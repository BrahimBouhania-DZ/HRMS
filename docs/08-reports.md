## 1. استراتيجية التقارير

| المبدأ | التفصيل |
|---|---|
| **محرك واحد** | كل تقرير يُعرَّف بقالب (Definition) + فلاتر + مخرجات — محرك موحّد يخدم PDF/Excel/CSV |
| **ثنائي المسار** | خفيف: توليد فوري. ثقيل (آلاف الصفوف): **Job خلفي** + إشعار عند الجاهزية |

| **الأرشفة** | مخرجات التقارير تُخزَّن مؤقتًا (T-051) مع تاريخ انتهاء |
| **التدقيق** | كل توليد تسجله `reports_reportjob` (من، متى، فلاتر) |
| **RTL/LTR** | مخرجات PDF تدعم العربية RTL بخط عربي سليم |

## 3. التصدير: PDF / Excel / CSV

| الصيغة | التقنية المقترحة | الاعتبارات |
|---|---|---|
| **PDF** | WeasyPrint (HTML→PDF) | دعم **RTL عربي** كامل، خطوط عربية مدمجة، طباعة A4، قسائم بعناوين شفافة |
| **Excel (.xlsx)** | openpyxl | أوراق متعددة، تنسيق أعمدة، أرقام كـ NUMERIC (لا نصوص)، صفوف مجمعة |
| **CSV** | csv module + UTF-8 BOM | التوافق مع Excel للعربية (BOM أساسي)؛ `delimiter` قابل للتكوين |
| **الطباعة** | نافذة طباعة المتصفح للـ HTML/PDF | أنماط `@media print` (إخفاء القوائم والأزرار) |

### قواعد الصياغة

| القاعدة | التفصيل |
|---|---|
| الترويسة | شعار + اسم الشركة + اسم التقرير + الفترة + التاريخ + المستخدم + اللغة |
| التواقيع | حقل توقيع/ختم للمستندات الرسمية (قسيمة، كشف بنك) |
| الأرقام | تنسيق محلي (الفواصل/الكسور) + العملة من إعداد الفرع |
| الصفحات | ترقيم + "تم التوليد بواسطة HRMS" + نسخة رقم |
| التوقيع الإلكتروني | على المستندات المعتمدة (قسيمة/عقد) رمز تحقق + وقت |

## 4. البحث والفلترة والطباعة

| المكوّن | التفصيل |
|---|---|
| **شريط الفلاتر** | كل تقرير له فلاتر معرَّفة (فرع/قسم/فترة/حالة/موظف...) مع قيم مسبقة ذكية (آخر شهر) |
| **الفلاتر المحفوظة** | حفظ/تحميل مجموعات فلاتر كقوالب شخصية |
| **البحث داخل النتائج** | بحث نصي لحظي داخل الصفحة + بحث خادم عند الكبر |
| **الترتيب** | فرز على أي عمود + تجميع (Group by) |
| **الطباعة** | زر طباعة على المعاينة؛ تنسيق `@media print` |
| **الجدولة** | جدولة تقرير دوري → ملف جديد في كل تنفيذ → إشعار |
| **المشاركة** | رابط محمي بصلاحية (داخل LAN) — لا ملفات تُرسل عبر بريد خارجي |

## 5. التقارير المجدولة والتلقائية

| البند | التفصيل |
|---|---|---|
| التكوين | `reports_reportdefinition` (قوالب) + جدولة في cron عبر `manage.py run_scheduled_reports` |
| أمثلة | نشرة حضور الصباح (كل يوم 08:30)، ملخص الإجازات (الاثنين)، كشف الرواتب (الخميس قبل الإغلاق) |
| المستلمون | أفراد محددون أو دور (من `reports_reportjob`) |
| المخرجات | توليد تلقائي PDF/Excel + إشعار داخل النظام + بريد LAN (اختياري) |
| الفشل | إعادة محاولة + إشعار IT |
| الترتيب | أولوية تنفيذ خلفية دون إبطاء النظام التفاعلي |

> **✅ منفَّذ (T-REP-5):** نماذج `ReportDefinition/ReportJob/ReportGeneratedFile` + خدمة `apps/reports/scheduling.py` + أمر `run_scheduled_reports` (cron يومي) + صفحة "التقارير المجدولة" (`reports:generated`) + تنزيل الملفات + إشعار المستلمين + تسجيل في سجل التدقيق. الافتراضي: تنفيذ عبر cron بدل Celery (لغياب Celery في المتطلبات — قرار توثيقي في `12`).

## 6. معمارية تنفيذ التقارير

```
واجهة (اختيار قالب + فلاتر)
   │
   ▼
ReportService (تحقق صلاحية + نطاق + ترجمة فلاتر)
   │
   ▼
مستخرج بيانات (QuerySet مُفلتر + Paginated/Streamed) ──► PostgreSQL
   │
   ▼
محرك تقديم:
   ├─ PDF (WeasyPrint, قالب RTL)
   ├─ Excel (openpyxl)
   └─ CSV
   ▼
تخزين (reports_generatedfile) + إشعار + تنزيل
```

| التحسين | التفصيل |
|---|---|
| التخزين المؤقت | تقارير شائعة بنفس الفلاتر تُخدم من cache لفترة |
| الـ Streaming | التقارير الضخمة تُكتب للملف على دفعات (لا في الذاكرة) |
| Aggregation | كل التجميع في SQL (SUM/COUNT/GROUP BY) وليس في بايثون |
| الفهرسة | الاعتماد على فهارس `03` §4 |

## 10. تحذيرات وقرارات تصميمية (Alert Box)

1. **⚠️ لا تحميل كامل في الذاكرة**: تقرير 5000 موظف × عناصر رواتب = عشرات الآلاف من الصفوف — استخدم Streaming/تجميع SQL.
2. **⚠️ CSV للعربية**: بدون UTF-8 BOM يفتح Excel العربي بشكل مكسور — BOM إلزامي.
3. **⚠️ RTL في PDF**: لا تعتمد على محركات لا تدعم العربية (RTL)؛ WeasyPrint/ReportLab بخط عربي مُدار.
4. **⚠️ النطاق القانوني**: سجل رواتب ≥ 7 سنوات (قانوني) — الأرشفة لا تحذف، أرشيف منفصل.
5. **⚠️ كل تقرير يخضع للصلاحيات**: تقرير "سجل التدقيق" و"الرواتب التفصيلية" حساسان — نطاق + تدقيق توليد.
