## 1. مبادئ تصميم الواجهة

| المبدأ | التفصيل |
|---|---|
| **RTL/LTR ديناميكي** | عند `ar` → `direction: rtl` وكل الحواف تنعكس (استخدم Logical Properties: `margin-inline-start`). عند `fr/en` → `ltr`. |
| **i18n كامل** | لا نص مدمج في HTML/JS — كل النصوص عبر `{% trans %}`/ملفات `.po`/JSON. حتى الرسائل والتواريخ والأرقام محلية. |
| **نظام تصميم موحّد** | مكوّنات مشتركة: بطاقات، جداول، نماذج، أزرار، شرائط تنبيه، شارات. خط واحد (عربي+لاتيني): مثل Cairo/Tajawal للعربي + Inter للاتيني. |
| **اتجاه القراءة** | القوائم والجداول تعكس الاتجاه؛ أرقام العملات تُنسّق محليًا (fr يفضل مسافات، ar يفضل رموز). |
| **ألوان** | لوحة تحكم إدارية هادئة: أساسي أزرق داكن، تحذير برتقالي، نجاح أخضر، خطأ أحمر. تباين AA. |
| **الوضع الليلي** | اختياري (افتراضي فاتح). |
| **التجاوب** | متصفح + أجهزة لوحية عند المداخل (شاشة QR). |
| **إمكانية الوصول** | WCAG 2.1 AA: تسميات لكل الحقول، تنقّل بلوحة المفاتيح، تركيز مرئي. |
| **لوحات تحميل إرشادية** | صفحات القوائم تفتح فورًا مع `Skeleton`، والتقارير الثقيلة تُولّد في الخلفية (Job) وتُنبه عند الجاهزية. |

## 3. الهيكل العام للصفحة (Layout Template)

```
┌────────────────────────────────────────────────────────────┐
│ الشريط العلوي (Topbar):                                    │
│ [☰ القائمة] [شعار النظام] [🔍 بحث موحّد] [🌐 اللغة] [🔔 3] [👤] │
├──────────┬─────────────────────────────────────────────────┤
│ الشريط    │                                                │
│ الجانبي   │   محتوى الصفحة (Content)                       │
│ (Sidenav) │   - رأس الصفحة (عنوان + أزرار إجراء)            │
│ -لوحة     │   - بطاقات KPIs (حسب الصفحة)                   │
│ -الموظفون │   - شريط فلاتر + زر تصدير                       │
│ -الحضور   │   - جدول / بطاقات / نموذج                       │
│ -الإجازات │   - ترقيم الصفحات                               │
│ -الرواتب  │                                                │
│ ...       │                                                │
├──────────┴─────────────────────────────────────────────────┤
│ التذييل: حقوق + إصدار النظام + زر تحديث اللغة               │
└────────────────────────────────────────────────────────────┘
```

- **Sidenav** يظهر حسب الدور (صلاحيات `05`).
- **Topbar** ثابت لضمان توفر البحث واللغة والإشعارات في كل صفحة.
- كل صفحة لها **رأس موحّد**: العنوان، الوصف المختصر، أزرار الإجراءات، وأحيانًا `Breadcrumbs`.

## 4. الصفحات التفصيلية

> **تنسيق لكل صفحة:** الهدف | العناصر | الأزرار | الجداول | الفلاتر | الصلاحيات | السيناريوهات.

---

### 4.1 Login (تسجيل الدخول)

| البند | التفصيل |
|---|---|
| **الهدف** | مصادقة المستخدم وتوجيهه حسب الدور. |
| **العناصر** | حقل اسم المستخدم/البريد، حقل كلمة المرور، زر اللغة (AR/FR/EN) أعلى الصفحة، خيار "تذكرني"، رابط "نسيت كلمة المرور". |
| **الأزرار** | `تسجيل الدخول`، `استعادة كلمة المرور`. |
| **الصلاحيات** | Guest (بدون حساب). |
| **السيناريوهات** | نجاح → توجيه للوحة حسب الدور. فشل → رسالة خطأ محلية مع عدّاد محاولات. حساب مقفل → رسالة قفل + زر اتصال بالمسؤول. إجبار تغيير كلمة المرور أول دخول. MFA (للمسؤولين) → شاشة رمز TOTP. |

### 4.2 Dashboard (لوحة التحكم)

| البند | التفصيل |
|---|---|
| **الهدف** | لمحة تنفيذية فورية: صحة الشركة وحركة اليوم دون الدخول لأي وحدة. |
| **عناصر KPI** | عدد الموظفين، الحاضرون اليوم، المتغيبون، المتأخرون، الإجازات الحالية، العقود المنتهية، الموظفون الجدد، طلبات الإجازة المعلقة. |
| **مخططات** | حضور/غياب آخر 30 يومًا (خطي)، توزيع الموظفين حسب القسم (دائري)، ساعات العمل الأسبوعية (أعمدة). |
| **قوائم مختصرة** | آخر التنبيهات، آخر العمليات (من Audit Log)، طلبات بانتظار موافقتي. |
| **بطاقة AI** | "رؤى اليوم": خلاصة ذكية مولّدة (مثال: "ارتفاع غياب قسم الإنتاج 20% هذا الأسبوع"). |
| **الأزرار** | `عرض الكل` لكل قائمة، `فتح التقارير`. |
| **الصلاحيات** | حسب الدور: الموظف يرى ملفه وحضوره فقط؛ المشرف يرى فريقه؛ HR/الإدارة يرى المؤشرات العامة. |
| **السيناريوهات** | تحديث تلقائي كل دقيقة لعناوين الحضور. النقر على KPI يوجه لصفحة مفلترة مسبقًا. |

### 4.3 Employees (الموظفون)

| البند | التفصيل |
|---|---|
| **الهدف** | إدارة دورة حياة الموظف كاملة. |
| **العناصر** | جدول الموظفين، شريط بحث موحّد، فلاتر (فرع/قسم/حالة وظيفية/منصب)، عرض بطاقات أو جدول. |
| **الأزرار** | `إضافة موظف`، `استيراد Excel`، `تصدير`، `توليد QR`، `طباعة بطاقة`، لكل صف: `عرض`/`تعديل`/`إنهاء`/`تعطيل`. |
| **الجدول (أعمدة)** | الرمز، الاسم (باللغة المختارة)، القسم، المنصب، الفرع، الحالة، تاريخ التوظيف، رقم الهاتف، إجراءات. |
| **الفلاتر** | الفرع، القسم، الحالة، تاريخ التوظيف (من/إلى)، كلمة بحث. |
| **الصلاحيات** | HR: إضافة/تعديل. المشرف: عرض فريقه. المحاسب: عرض بيانات غير رواتب. الموظف: ملفه فقط. |
| **السيناريوهات** | إضافة موظف → إنشاء ملف + حساب + QR تلقائي. إنهاء → تجميد الحساب وإلغاء QR وفتح تسوية نهاية الخدمة. استيراد جماعي → معاينة الأخطاء قبل الحفظ. |

| الوثائق | وثائق الموظف + صلاحيات + إشعار انتهاء |
| QR | عرض/إعادة توليد/إلغاء/طباعة (انظر `06`) |
| الحضور | شهري + تفاصيل يومية + استثناءات |
| الإجازات | أرصدة + طلبات |
| الرواتب | قسائم + عناصر |
| التقييمات | دورات التقييم + النتائج + PIP |
| التدريب | الدورات المسجلة + الشهادات |

### 4.4 Departments (الأقسام والفروع والمناصب)

| البند | التفصيل |
|---|---|
| **الهدف** | بناء الهيكل التنظيمي شجريًا. |
| **العناصر** | شجرة أقسام (توسيع/طي)، جدول الفروع، جدول المناصب، تعيين مشرف لكل قسم. |
| **الأزرار** | `إضافة قسم/فرع/منصب`، `نقل قسم`، `تعطيل`. |
| **الصلاحيات** | HR Manager + Admin فقط. |
| **السيناريوهات** | إنشاء قسم تحت قسم (شجرة بلا حد). تعطيل قسم يمنع تعيين موظفين جدد دون مساس بالتاريخ. |

### 4.5 Attendance (الحضور والانصراف)

| البند | التفصيل |
|---|---|
| **الهدف** | تسجيل ومتابعة وتصحيح حضور كل الموظفين. |
| **المسح المباشر (وضع المدخل)** | شاشة بكاميرا/إدخال QR: تعرض أسماء المسحين لحظيًا بحالة خضراء/حمراء + صورة مصغرة + ملاحظة "متأخر". |
| **لوحة اليوم** | جدول أسماء + ساعة دخول/خروج + حالة (حاضر/متأخر/غائب/إجازة/مأمورية). |
| **السجل/الأرشيف** | جدول تفصيلي: اليوم، دخول، خروج، ساعات، تأخير، انصراف مبكر، إضافي، المصدر (QR/يدوي/قارئ). |
| **الاستثناءات** | طلبات (إذن/مأمورية/تعويض) + تصحيحات موظفين بانتظار الموافقة. |
| **الفلاتر** | التاريخ (نطاق)، الفرع، القسم، الموظف، الحالة، المصدر. |
| **الأزرار** | `تأكيد يدوي`، `إضافة استثناء`، `تصحيح حضور`، `تصدير`. |
| **الصلاحيات** | المشرف: فريقه. HR: الكل + تصحيح. الموظف: شاشة QR للخروج/الدخول فقط. |
| **السيناريوهات** | مسح QR مرفوض (مكرر/فرع خاطئ/مقفل) → شاشة خطأ واضحة + تنبيه للمشرف. عطل القارئ → بوابة تسجيل يدوي بمسؤول. |

### 4.6 Leave (الإجازات)

| البند | التفصيل |
|---|---|
| **الهدف** | طلب وإدارة الإجازات والأرصدة. |
| **صفحة الموظف** | نموذج (النوع/من/إلى/التعليل) + مؤشر الرصيد المتبقي حي + قائمة طلباتي بحالاتها. |
| **صندوق الموافقات** | طلبات بانتظار المستخدم (نوعه في السلسلة) + تفاصيل + أزرار `قبول`/`رفض` + تعليق. |
| **لوحة الأرصدة** | جدول موظف × نوع × رصيد (استحقاق/مستخدم/متبقي/مرحّل). |
| **الإعداد** | أنواع الإجازات، العطل الرسمية، سياسة الترحيل والتصفير. |
| **الفلاتر** | الحالة، النوع، القسم، الفترة. |
| **الصلاحيات** | الموظف: طلباته. المشرف: طلبات فريقه حسب السلسلة. HR: كل شيء + تسوية أرصدة. |
| **السيناريوهات** | طلب برصيد ناقص → منع مع اقتراح مرهونة إن سمح النوع. إلغاء معتمد → استعادة الرصيد. تعارض مع عطلة رسمية → تنبيه. |

### 4.7 Payroll (الرواتب)

| البند | التفصيل |
|---|---|
| **الهدف** | حساب وإصدار الرواتب بأمان وشفافية. |
| **دورات (Runs)** | جدول الدورات: الفترة، الفرع، الحالة، الإجمالي، صافي، الصافي المدفوع. |
| **معالج الدورة** | خطوات: مراجعة الحضور → توليد → مراجعة فروقات → اعتماد → تجميد. |
| **جدول الكشف** | موظف، أساسي، عناصر، عمل إضافي، خصومات، صافي، حالة القسيمة. |
| **القسيمة (Payslip)** | قالب PDF: بيانات الموظف، عناصر بالتفصيل، إجمالي/خصومات/صافي، توقيعات، رمز تحقق. |
| **عناصر الأجر (إعداد)** | جدول: رمز، اسم، نوع (إضافة/خصم)، طريقة حساب. |
| **نهاية الخدمة** | حساب تلقائي حسب القانون + مسار اعتماد. |
| **الفلاتر** | الفترة، الفرع، القسم، حالة الدورة. |
| **الصلاحيات** | المحاسب: توليد/مراجعة. HR: اعتماد/تجميد. الموظف: قسيمته فقط. Admin: إعدادات عناصر الأجر. |
| **السيناريوهات** | تعديل على فترة مجمّدة → يُرفض إلا بإذن Admin + أثر تدقيق. تصدير بنك (Excel) بعد الاعتماد. |

### 4.9 Documents (الوثائق)

|---|---|

| **الأزرار** | `رفع`، `تعديل صلاحيات`، `إصدار جديد`، `تحميل` (حسب الصلاحية)، `حذف منطقي`. |

### 4.11 AI Assistant (المساعد الذكي) — التفاصيل الكاملة في `07`

| البند | التفصيل |

| **الهدف** | إدارة حساب المستخدم. |
| **العناصر** | بيانات الحساب، تغيير كلمة المرور، تفضيلات اللغة والمنطقة، إعدادات الإشعارات، الجلسات النشطة (إنهاء عن بعد). |
| **الصفحات** | إعدادات الحساب، تغيير كلمة المرور، أمان الحساب (MFA). |

## 5. نظام البحث الموحّد (Global Search)

| البند | التفصيل |
|---|---|
| **الموقع** | Topbar — متاح في كل الصفحات. |
| **المصادر** | الموظفون (اسم/رمز/هاتف/بريد/رقم هوية/QR)، الأقسام، الوثائق، العقود، الإجازات، الرواتب (رقم قسيمة). |
| **السلوك** | نطق فوري (`debounce`) + نتائج مجمعة حسب النوع + زر "فتح" لكل نتيجة. |
| **النطاق** | مقيد بصلاحيات المستخدم (الموظف يبحث في نطاقه فقط). |
| **السيناريو** | كتابة "محمد" → تظهر بطاقات: موظفون (اسم/قسم)، وثائق، طلبات إجازة مرتبطة. |

## 6. مركز الإشعارات (Notification Center)

| البند | التفصيل |
|---|---|
| **الهدف** | تنبيه المستخدم بكل الأحداث الهامة في مكان واحد. |
| **العناصر** | جرس في Topbar بعدّاد غير المقروءة، لوحة جانبية/صفحة بقائمة، تبويبات (الكل/غير المقروءة/المهمة)، تفضيلات. |
| **أنواع التنبيهات** | انتهاء عقد/وثيقة، قرب موعد إجازة، تأخر، غياب متكرر، طلب جديد بانتظار الموافقة، نتيجة طلب، قسيمة جاهزة، نهاية فترة تجربة، فشل نسخ احتياطي، رؤية ذكية. |
| **السلوك** | كل نوع له أيقونة ولون ومسار للصفحة المعنية. قراءة تلقائية عند الفتح + زر "تحديد الكل كمقروء". |
| **الجدولة** | من `notif_scheduledalert` (انظر `03`) — مهام Celery تفحص يوميًا. |
| **التفضيلات** | المستخدم يختار القنوات (داخل النظام/بريد LAN) لكل نوع. |

## 7. حالات الفراغ والخطأ والتحميل

| الحالة | السلوك |
|---|---|
| **لا بيانات** | صورة + رسالة i18n + زر إجراء (مثال: "لا يوجد موظفون بعد — أضف أول موظف"). |

| **تحميل بطيء** | Skeleton للأجزاء، وبار تقدم للتقارير الخلفية. |
| **صلاحية مرفوضة** | صفحة 403 بلغة المستخدم + رابط للوحة. |

## 8. تحذيرات وقرارات تصميمية (Alert Box)

1. **⚠️ RTL من أول بكسل**: استخدم `Logical Properties` و `dir` ديناميكي؛ عدم الالتزام يجعل الإصلاح لاحقًا مكلفًا جدًا.
2. **⚠️ البحث العربي**: اختبر `unaccent` + FTS عربي مبكرًا — اسم "أحمد/Ahmed/Ahmed" يجب أن يلتقط.
3. **⚠️ الواجهة ثقيلة؟** إبقاء SSR + HTMX لتجنب جلب 5K صف دفعة واحدة — كل الجداول مفلترة ومصفحة على الخادم.
4. **⚠️ الشاشات عند المداخل**: شاشة المسح يجب أن تعمل على تابلت/متصفح منخفض الموارد وبدون قفل.
5. **⚠️ طباعة البطاقات**: تصميم قالب بطاقة موظف (A4، عدة بطاقات) بأبعاد دقيقة مع QR قابل للمسح — راجع `06`.
