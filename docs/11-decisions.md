## 5. مبادئ هندسية غير قابلة للتفاوض

1. الحذف المنطقي فقط (Soft Delete) + سجل تدقيق append-only.
2. الفصل الوظيفي (SoD): من يولّد كشف الراتب لا يعتمده.
3. كل البيانات الحساسة مشفرة (بنكية/هوية) + نطاقات صلاحيات إلزامية.
4. كل Query يحترم نطاق المستخدم (Scope) — لا استثناء حتى للـ AI.
5. المبالغ المالية `NUMERIC(15,2)` — لا FLOAT.
6. الأداء المرجعي: 5000 موظف / 200 مستخدم متزامن (Partitioning + فهارس + تقارير خلفية).
