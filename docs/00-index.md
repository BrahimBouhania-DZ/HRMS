## غرض هذه الوثائق

هذه الحزمة هي **العقد الهندسي الكامل** لنظام HRMS. هدفها:

1. توثيق **الاحتياجات** قبل التنفيذ (ما الذي يجب أن يفعله النظام).
2. توثيق **التصميم** (كيف يُبنى النظام: بنية، قاعدة بيانات، واجهات، أمان).
3. توفير **مصدر واحد للحقيقة** لكل فريق (تطوير، جودة، تشغيل، موارد بشرية).
4. تكون **قابلة للتحويل إلى مهام تطوير** (Development Tasks / User Stories) لكل إصدار.
5. ضمان أن كل قرار معماري **قابل للتوسع** مستقبلاً (5000+ موظف).

## القرارات التأسيسية المعتمدة

اعتُمدت هذه القرارات مع صاحب المشروع قبل البدء بالتصميم:

| القرار | الاختيار | المبرر |
|---|---|---|
| لغة الواجهة | عربي (RTL) / فرنسي / إنجليزي | متطلبات العمل |
| نظام الترجمة | i18n كامل (لا نصوص مدمجة في الكود) | قابلية الترجمة والتبديل |
| حزمة التقنيات | **Django + PostgreSQL** | Auth وi18n وAdmin وORM مدمجة، ناضجة للأنظمة الإدارية |
| قاعدة البيانات | PostgreSQL (محلية على الخادم) | أداء، نضج، FTS، JSONB، ترحيلات |
| الوصول | متصفح فقط عبر الشبكة المحلية | لا يحتاج إنترنت |
| تشغيل الخادم | Server مركزي داخل الشركة | امتلاك كامل للبيانات |
| أجهزة QR | هواتف الموظفين + قارئات ثابتة عند المداخل | مرونة في الفروع الكبيرة |
| المقياس المرجعي | 5000+ موظف، فروع متعددة | تصاميم قابلة للتوسع أفقيًا |
| منهجية التصميم | Clean Architecture + SOLID + DDD عند الحاجة | فصل الاهتمامات وقابلية الصيانة |

## الترتيب المقترح للقراءة والاعتماد

```
00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10
```

- **لصاحب القرار / إدارة الموارد البشرية:** اقرأ `01` و `10` للتحقق من اكتمال النطاق.
- **للمهندس المعماري:** اقرأ `02` و `03` و `09`.
- **للفريق التقني:** اقرأ `02` → `03` → `04` → `06` → `07` → `08`.
- **لجودة البرمجيات:** راجع `01` (المتطلبات) مع `08` و `09` لبناء حالات الاختبار.

## قواعد عامة تلتزم بها هذه الحزمة

1. **الترقيم الموحد:** كل متطلب وكل مكون وكل جدول يحمل معرّفًا فريدًا قابلًا للترجمة إلى Task/User Story.
2. **قابلية التحويل:** كل قسم يختم بجدول `مخرجات التطوير (Development Tasks)`.
3. **قابلية التوسع:** أي تصميم يُكتب بافتراض 5000+ موظف وعدة فروع.
4. **التحذير المبكر:** كل وثيقة تتضمن قسم **"تحذيرات وقرارات تصميمية"** تسبق التنفيذ.
5. **لا توجد نصوص مدمجة:** كل النصوص تمر عبر i18n.
